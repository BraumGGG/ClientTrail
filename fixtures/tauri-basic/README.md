# Tauri Basic Fixture

This fixture is used by the client-testing project to validate the Tauri 2 adapter. Install dependencies in this directory, build the debug application, then run `pnpm test:e2e` on a supported desktop runner.

Prerequisites: Node.js 20+, pnpm 11+, Rust stable (current Tauri dependencies require rustc 1.88+), and the platform desktop build tools.
